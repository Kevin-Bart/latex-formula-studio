# LaTeX Formula Studio

A lightweight, interactive web application built with Streamlit and TeX Live to render and export mathematical expressions on the fly.

### Features
- **Live Preview & Compiling**: Write LaTeX math equations and compile them directly into clean, publication-ready renders.
- **Multiple Formats**: Export directly to **Vector PDF** (via `pdflatex`), **Transparent PNG** (via `dvipng`), and **High-Quality JPG**.
- **Layout Control**: Adjust line/box widths dynamically to keep equation labels close to formulas without artificial whitespace.
- **Syntax Help**: Built-in guide covering unnumbered expressions (`equation*`), custom tags (`\tag{...}`), multi-line systems (`align*`), and matrices.
